# Grill with docs

- Read relevant records through [project-knowledge](../project-knowledge/SKILL.md).
- Use [grilling](../grilling/SKILL.md) and [domain-modeling](../domain-modeling/SKILL.md) together. Save agreed terms and decisions within scope through project knowledge.
- On spec request, synthesize the settled problem, desired behavior, scope, acceptance examples, and open decisions. Link terms and ADRs. Use project knowledge for saved specs. Skip a fresh interview.

The interview and spec synthesis adapt work by [Matt Pocock](https://github.com/mattpocock/skills/blob/3cca18b368ae95cdbdebbff572ccafa662551015/skills/engineering/grill-with-docs/SKILL.md). See [LICENSE](LICENSE) for the MIT notice.
