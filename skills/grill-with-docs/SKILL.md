# Grill with docs

Use [grilling](../grilling/SKILL.md) to lead questions and
[domain-modeling](../domain-modeling/SKILL.md) to refine terms and decisions within
those rounds. Do not start a second interview. Read supplied skill files as needed;
a host-specific skill tool is not required.

Use [project-knowledge](../project-knowledge/SKILL.md) for current sources and persistent
results. Follow with [to-spec](../to-spec/SKILL.md) for requested synthesis and
[to-tickets](../to-tickets/SKILL.md) when larger work benefits from decomposition.
These handoffs preserve existing authority; documentation creates no new permission.
