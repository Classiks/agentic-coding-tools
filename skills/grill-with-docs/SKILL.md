# Grill with docs

Read relevant project records first with [project-knowledge](../project-knowledge/SKILL.md).
For an interview, use [grilling](../grilling/SKILL.md) to lead, drawing on
[domain-modeling](../domain-modeling/SKILL.md) to refine terms and decisions during
the same rounds. Save agreed terms and decisions through project knowledge.

When asked for a spec, synthesize the settled discussion into the problem, desired
behavior, scope boundaries, concrete acceptance examples, and open decisions without
restarting the interview. Link existing terms and ADRs and use project knowledge
for any saved spec.

The interview and spec synthesis adapt work by [Matt Pocock](https://github.com/mattpocock/skills/blob/3cca18b368ae95cdbdebbff572ccafa662551015/skills/engineering/grill-with-docs/SKILL.md). See [LICENSE](LICENSE) for the MIT notice.
