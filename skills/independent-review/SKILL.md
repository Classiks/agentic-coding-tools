name: independent-review
description: Obtain a separate agent's second opinion on a decision, delivery candidate, or disputed result when the user or project requests it.
---

# Independent review

- Brief the reviewer on a fixed snapshot or diff, or a concrete decision. Give explicit scope, criteria, references, and access to run their own checks. Use the model, reasoning level, and thresholds set by the user or project.
- For fresh confirmation of a disputed result, pass along factual evidence and reproduction context. Omit prior verdicts and scores.
- Ask for findings with observed consequences, the checks performed and scope covered, and explicit limits or blind spots. Require the same account of checks when the reviewer finds no issues.
- The reviewer needs explicit authority to edit. Keep any reviewer edits separate from the verdict and identify which version the reviewer assessed.
- After fixes, recheck the affected behavior on the new version. Broaden review if the remaining risk warrants it. The lead or user makes the final decision.
